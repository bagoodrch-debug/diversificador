Alocador de Carteira

Planeje como distribuir seu investimento entre classes de ativos.

Pra que serve isso, na prática

A maioria das pessoas sabe, em teoria, que "não deve colocar todo o dinheiro numa coisa só" — mas na hora de decidir quanto vai pra renda fixa, quanto vai pra ações, quanto vai pra fora do país, a conta trava. O Alocador de Carteira existe pra tirar essa decisão da cabeça e transformar em números concretos: você escolhe os percentuais entre cinco classes de ativos, e a ferramenta traduz isso em reais, sugere ativos reais dentro de cada classe (com cotação atualizada) e calcula quantas cotas ou títulos caberiam no valor alocado.

Como usar

  1. Informe o valor total que você tem disponível pra investir.
  2. Ajuste os sliders de cada classe — Renda Fixa, Ações, Ações no Exterior, FIIs e Ouro — até chegar numa distribuição que faça sentido pro seu perfil. Mexer num slider redistribui os outros automaticamente, sempre somando 100%.
  3. Pra cada classe, a ferramenta sugere ativos reais (com preço atualizado) e quantas cotas/títulos você conseguiria comprar com o valor alocado ali.
  4. Não gostou de uma sugestão? Dá pra ocultar (ícone de olho, sem apagar) ou remover de vez, e adicionar outro ativo manualmente ou por busca.

Tudo o que você configura fica salvo automaticamente no seu navegador — não precisa recomeçar do zero a cada visita.

De onde vêm os dados

  • Ações, BDRs, FIIs e ETF de ouro: API da Brapi (brapi.dev).
  • Ouro spot (XAU/BRL): AwesomeAPI.
  • Títulos públicos: API pública do Tesouro Direto.

Por que o site não chama a Brapi diretamente do navegador

Este é um site estático hospedado no GitHub Pages — ele não tem um servidor próprio rodando o tempo todo. Se o token da Brapi fosse colocado no JavaScript do site, qualquer visitante poderia abrir as ferramentas de desenvolvedor do navegador e copiar a chave em segundos. Por isso a chave nunca entra em nenhum arquivo público do repositório.

  1. O token da Brapi fica guardado apenas em GitHub Actions Secrets, um cofre do próprio GitHub, associado ao repositório.
  2. Um workflow (.github/workflows/atualizar-cotacoes.yml) roda automaticamente nos servidores do GitHub.
  3. Esse workflow executa scripts/atualizar-cotacoes.mjs, que busca as cotações usando o token e grava o resultado em dados/cotacoes.json.
  4. O site (rodando no navegador de cada visitante) só lê esse arquivo dados/cotacoes.json — que é público, mas não contém nenhuma credencial.
Resultado: o token nunca trafega para o navegador do visitante e nunca aparece no histórico do Git, mesmo o repositório sendo público.

Como o cálculo das sugestões funciona

Para cada classe de ativo, o valor alocado é dividido igualmente entre os ativos ativos (não excluídos) daquela classe. A quantidade sugerida de cotas/títulos é o valor por ativo dividido pelo preço unitário, arredondada para baixo. Isso é apenas uma ilustração de proporção — não considera lote mínimo real de negociação, custos de corretagem ou impostos.

Perguntas frequentes

A ferramenta me diz o que comprar?

Não. Ela mostra exemplos reais dentro de cada classe pra deixar a simulação concreta, mas a escolha final — e o risco dela — é sua. Não é recomendação de investimento.

Os dados são em tempo real?

Não no sentido de milissegundo a milissegundo — refletem o último ciclo do robô que atualiza as cotações. Para a maioria das decisões de alocação, essa defasagem é irrelevante.

Posso simular uma carteira que já tenho, em vez de uma nova?

Sim — só informar o valor total que já está investido e ajustar os percentuais pra bater com sua distribuição atual, ou testar cenários de rebalanceamento.

Limitações

  • Não considera Imposto de Renda, taxas de corretagem ou de administração.
  • As sugestões cobrem uma lista curada de ativos, não a bolsa inteira.
  • Não é recomendação de investimento nem consultoria financeira.
